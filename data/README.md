# 데이터 설명

## kofic_최종_영화_드롭률_데이터셋.xlsx

- 2023~2025년 개봉 영화 약 130편의 1~4주차 주말 관객수 데이터
- 출처: 영화진흥위원회(KOFIC) 오픈 API + KOFIC 통합전산망

### 생성 과정
1. KOFIC 오픈 API로 1~4주차 주말(금+토+일) 관객수 자동 수집
2. API TOP 50 한계로 결측된 3·4주차 영화는 KOFIC 통합전산망에서 수동 보완
3. 자동 수집분 + 수동 보완분 병합 → 최종 파일 완성

### 주요 컬럼
| 컬럼명 | 설명 |
|--------|------|
| 영화명 | KOFIC 정식 영화명 |
| 개봉일 | 개봉 날짜 |
| 체급 | 중형 / 중대형 / 대형 |
| 누적관객수 | 최종 누적 관객 수 |
| 1~4주차_주말관객 | 각 주차 금+토+일 관객수 합산 |
| 드롭률_1to2 | 1→2주차 드롭률(%) |
| 분류 | 정상_드롭 / 공휴일_역주행 / 순수_역주행 등 |
