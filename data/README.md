# 데이터 폴더 설명

본 폴더는 프로젝트의 원본·중간·최종 데이터를 담고 있습니다.

## 파일 목록

| 파일 | 단계 | 설명 |
|---|---|---|
| `01_kofic_최종_영화_드롭률_데이터셋.xlsx` | 수집 | KOFIC API로 수집한 영화별 주차별 관객수 패널 데이터 |
| `naver_검색량_단독수집.xlsx` | 수집 | 네이버 단독 검색량 (영화명 단독 검색) |
| `naver_검색량_검증형수집.xlsx` | 수집 | 네이버 검증형 검색량 (후기·리뷰·평점·관람평) |
| `naver_검색량_기대형수집.xlsx` | 수집 | 네이버 기대형 검색량 (예고편·시사회·개봉일·출연) |
| `youtube_수집_최종.xlsx` | 수집 | 유튜브 공식 예고편 조회수·좋아요·댓글 |
| `master_dataset_전체.xlsx` | 통합 | 130편 × 33변수 마스터 데이터셋 |
| `master_dataset_중형.xlsx` | 통합 | 중형 영화만 추출한 분석용 데이터셋 |

## 주요 컬럼 설명

| 컬럼명 | 설명 |
|---|---|
| 영화명 | KOFIC 정식 영화명 |
| 체급 | 중형 / 중대형 / 대형 (누적관객수 기준) |
| 드롭률_1to2 | 1→2주차 주말 관객 감소율 (%) |
| 검증_지속력 | 후반 검증 검색량 / 개봉일 검증 검색량 |
| 검증_강도 | 개봉 시점 검증 검색량의 크기 |
| 분류 | 정상_드롭 / 정상_드롭_1주차부스트 / 순수_역주행 / 공휴일_역주행 / 데이터_부족 |
