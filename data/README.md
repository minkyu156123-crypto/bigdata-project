#  네이버 검색 반응으로 영화 흥행 지속성 예측

> **입소문은 "강하게 한 번"이 아니라 "길게 가는 것"이 영화 흥행을 결정한다.**

2023~2025년 개봉한 중형 영화를 대상으로, 네이버 검색·유튜브 디지털 반응 데이터를 활용해
영화의 **흥행 지속성(2주차 드롭률)** 을 결정하는 요인을 분석한 빅데이터 프로젝트입니다.

---

##  프로젝트 개요

영화 흥행 분석은 보통 첫 주 성적이나 누적 관객수에 집중하지만, 본 프로젝트는
**"개봉 후 관객이 얼마나 오래 유지되는가"** 라는 흥행 지속성에 주목했습니다.

특히 마케팅 예산이 제한적인 **중형 영화(누적 50만~300만 명)** 는 입소문에 따라 흥행 곡선이
크게 갈리기 때문에, 디지털 검색 반응이 흥행 지속성을 예측하는 신호가 될 수 있다고 보았습니다.

**핵심 연구 질문**

> 디지털 반응의 *강도(얼마나 검색량이 많은가)* 와 *지속력(검색이 얼마나 오래 가는가)* 중
> 무엇이 영화의 흥행 지속성을 더 잘 설명하는가?

---

##  연구 가설

| 가설 | 내용 | 검정 방법 | 결과 |
|---|---|---|---|
| H1 | 영화 체급에 따라 흥행 곡선의 형태가 다르다 (중형은 절벽처럼, 대형은 언덕처럼 사라진다) | Kruskal-Wallis |  지지 |
| **H2**  | 디지털 반응의 *지속력*이 *강도*보다 흥행 지속성을 더 강하게 설명한다 | 다중회귀 모델 비교 |  강하게 지지 |
| H3 | 역주행 영화는 정상 흥행 영화와 디지털 반응 패턴이 통계적으로 다르다 | Mann-Whitney U + Cliff's δ |  지지 |

H2가 본 프로젝트의 **핵심 가설**이며, H1은 분석 대상(중형 영화)의 차별성을 입증하는 전제,
H3은 흥행 곡선의 예외 사례(역주행)를 설명하는 보강 분석입니다.

---

##  데이터

| 구분 | 출처 | 내용 |
|---|---|---|
| 흥행 데이터 | 영화진흥위원회(KOFIC) 오픈 API + 통합전산망 | 1~4주차 주말 관객수, 누적 관객수, 스크린 수 |
| 검색 데이터 | 네이버 데이터랩 API | 영화별 단독·기대·검증 검색량 (개봉 D-7 ~ D+7) |
| 영상 데이터 | YouTube Data API v3 | 공식 예고편 조회수·좋아요·댓글 |

**표본 구성** — 2023~2025년 개봉작 총 **130편**

| 체급 | 기준 (누적관객수) | 편수 |
|---|---|---|
| 중형 | 50만 ~ 300만 명 | 103편 (메인 분석 표본) |
| 중대형 | 300만 ~ 500만 명 | 14편 |
| 대형 | 500만 명 이상 | 13편 |

최종 산출물은 130편 × 33개 변수로 구성된 마스터 데이터셋입니다.

### 핵심 파생 변수

| 변수 | 정의 | 의미 |
|---|---|---|
|  검증_지속력 | 후반 검증 검색량 / 개봉일 검색량 | 관람평 검색이 얼마나 오래 지속되는가 |
| 검증_강도 | 개봉 시점 검증 검색량의 크기 | 디지털 반응의 순간적 세기 |
| 단독_사후사전비율 | 개봉 후 평균 / 개봉 전 평균 검색량 | 관심도 변화 |
| 드롭률_1to2 | (1주차 − 2주차 관객) / 1주차 관객 × 100 | 흥행 지속성 타겟 변수 |

> 드롭률은 금요일 공휴일 노이즈를 피하기 위해 토·일 관객 합산 기준으로 계산했습니다.

##  분석 파이프라인

프로젝트는 데이터 수집부터 모델 설계까지 10개의 노트북으로 구성됩니다.

| 노트북 | 단계 | 내용 |
|---|---|---|
| `01` KOFIC 관객수 수집 | 수집 | KOFIC API로 1~4주차 주말 관객수 수집 |
| `02` 공휴일 여부 분석 | 수집·전처리 | 주차별 공휴일 노이즈 통제 변수 생성 |
| `03` 네이버 검색 데이터 수집 | 수집 | 단독·기대·검증 검색량 수집 |
| `04` 유튜브 데이터 수집 | 수집 | 공식 예고편 조회수·좋아요·댓글 수집 |
| `05` 데이터 통합 마스터테이블 | 전처리 | 4개 소스 병합 → 130편 × 33변수 |
| `06` EDA | 탐색 | 분포·상관·이상치 분석, 시각화 |
| `07` 가설검정 H1 | 검정 | 체급별 흥행 곡선 차이 검정 |
| `08` 가설검정 H2 | 검정 | 지속력 vs 강도 설명력 비교 |
| `09` 가설검정 H3 | 검정 | 역주행 vs 정상 흥행 디지털 패턴 비교 |
| `10` 모델 설계 | 모델링 | 머신러닝 기반 가설 재검증 |

##  주요 결과

### H1 — 중형 영화는 절벽처럼 사라진다

체급별 흥행 곡선의 가파름(로그 감소 기울기)과 4주차 생존비율을 비교했습니다.
정규성 위배로 비모수 검정(Kruskal-Wallis)을 사용했습니다.

| 체급 | 로그 감소 기울기 (평균) | 4주차 생존비율 (평균) |
|---|---|---|
| 대형 | -0.152 | 0.520 |
| 중대형 | -0.200 | 0.318 |
| 중형 | **-0.362** | **0.169** |

중형 영화는 가장 가파르게 떨어지고 장기 잔존율도 가장 낮아, 흥행 곡선이 체급에 따라
구조적으로 다르다는 점이 확인되었습니다.

### H2 — 지속력이 강도를 압도한다 (핵심 결과) 

중형 영화 98편을 대상으로, 강도 변수군과 지속력 변수군의 설명력을 다중회귀로 비교했습니다.

| 모델 | 변수 구성 | R² |
|---|---|---|
| Model A | 강도 변수 5개 | 0.152 |
| Model B | 지속력 변수 2개 | **0.622** |
| Model C | 강도 + 지속력 전체 | 0.645 |
| Model D | 전체 + 통제변수 | 0.664 |

- 지속력 변수 2개만으로 강도 변수 5개보다 **약 4배 높은 설명력**을 보였습니다.
- 표준화 회귀계수에서 `검증_지속력`이 β = -0.60 (p<0.001)로 압도적 1위였고,
  지속력 변수군의 평균 |β|는 강도 변수군의 **약 5.4배**였습니다.
- 우도비 검정 결과 강도 변수 추가는 유의하지 않아(p=0.289), 지속력만으로 충분함이 확인되었습니다.

### H3 — 역주행 영화는 디지털 시그니처가 다르다

정상 흥행 영화(86편)와 순수 역주행 영화(13편)의 디지털 반응 패턴을 비교했습니다
(Mann-Whitney U, Bonferroni 보정).

| 변수 | Cliff's δ | 효과크기 | Bonferroni 통과 |
|---|---|---|---|
| 검증 검색의 지속력 | -0.754 | 큰 효과 | ✓ |
| 검증 검색 강도 | -0.692 | 큰 효과 | ✓ |
| 4주차 생존비율 | -0.662 | 큰 효과 | ✓ |

역주행 영화는 검증 검색의 지속력이 뚜렷하게 높았고, 반면 유튜브 변수들은 두 그룹 간
차이가 거의 없었습니다.

### 모델 설계 — 가설의 머신러닝 재검증

본 프로젝트에서 모델링은 예측 시스템 구축이 아니라, **가설검정 결과를 머신러닝
관점에서 재확인하는 보조 단계**입니다. 중형 98편(생존 60 / 절벽 38)에 대해
로지스틱 회귀·랜덤포레스트·XGBoost를 5-fold 교차검증으로 평가했습니다.

- 모델 AUC는 0.58~0.60 수준으로, 소표본(N=98)과 역주행 이상치의 영향으로 제한적이었습니다.
- 네이버 단독 모델과 네이버+유튜브 모델의 AUC 차이는 평균 -0.007로,
  **유튜브 변수 추가의 기여가 거의 없어 네이버 검색만으로 충분**함이 확인되었습니다.
- 세 모델 모두에서 `검증_지속력`이 변수 중요도 1순위로 나타나, 통계적 가설검정과
  머신러닝이 동일한 변수를 핵심으로 지목했습니다.

##  종합 결론

> **중형 영화의 흥행 지속성을 결정하는 것은 디지털 반응의 강도가 아니라 지속 시간이며,
> 이는 통계적 가설검정과 머신러닝 모델링 양쪽에서 일관되게 확인되었다.**

서로 다른 방법론(통계 검정·머신러닝)이 `검증_지속력`이라는 같은 변수를 1순위로 지목했다는
점이 본 발견의 강건성(robustness)을 뒷받침합니다.

##  한계 및 향후 과제

- 표본 규모(중형 98편)가 작아 머신러닝 모델의 예측 성능 자체는 제한적입니다.
- 음수 드롭률(역주행) 사례가 모델 학습에 노이즈로 작용했습니다.
   공휴일 효과로 인한 역주행은 통제변수와 분류 라벨로 분리했으나, 공휴일과 무관한 순수 입소문 역주행(13편)은 모델링 단계에서 별도로 분리하지 않아 학습 노이즈로 작용했다. 향후 이 사례들을 분리 학습하면 예측 성능을 보완할 수 있다.
- 향후 표본 확대와 역주행 사례 분리 학습을 통해 예측 성능을 보완할 수 있습니다.
- KOFIC API의 박스오피스 TOP 50 한계로 일부 영화의 3·4주차 데이터는 통합전산망에서
  수동 보완했습니다.
